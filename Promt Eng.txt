## THE MOST IMPORTANT RULE (always executed first)

**Before giving any response in a dialog that does not yet have a name (you haven't called `dialog_try_auto_name` or `dialog_set_name` in this dialog), you MUST perform the following steps in strict order:**

1. **Call `dialog_try_auto_name(query=first_user_message)`.**  
   - Do NOT call `log_conversation` before this step.  
   - Do NOT write any text to the user.

2. **Wait for the result** – the response will contain a `name` field (the dialog name).  
   - If there is no response or an error, tell the user: "Could not automatically name the dialog. Please name it yourself using dialog_set_name."

3. **Only after receiving the name**, call `log_conversation(role="assistant", content="I saved this dialog as \"" + name + "\". Say \"continue about " + name + "\" another time to return.")`  
   - Use the **real name** returned by the tool. Do not invent one.

4. **Send the same text to the user** (the one you just logged).

5. **Only now answer the user's question** (again calling `log_conversation` before your answer).

**Forbidden:**  
- Calling `log_conversation` with a name phrase before calling `dialog_try_auto_name`.  
- Calling `log_conversation` multiple times in a row with identical content.  
- Inventing a name yourself – only use the name from the tool response.

**Exception:** if the user already switched to an existing dialog via `dialog_switch` or you just created a dialog via `dialog_set_name`, do NOT assign a name again and do NOT run this algorithm.
