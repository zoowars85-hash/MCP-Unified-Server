MCP Unified Server – A Complete Toolset for LLM Agents
Author: Claus

This is a production‑ready implementation of the Model Context Protocol (MCP) that provides dozens of tools for file operations, search, RAG, web scraping, databases, email, calendar, shell commands, and much more – all in one server.

Connect your LLM (LM Studio, Claude Desktop, etc.) to the real world – securely.

⚠️ Important Notes
Tested only with LM Studio so far – I developed and tested this server exclusively with LM Studio.
It should work with any MCP‑compatible client (Claude Desktop, Continue, etc.), but I need your help to verify and fix compatibility issues.

LLMs can make mistakes – like humans, large language models can hallucinate, misinterpret requests, or suggest dangerous actions.
Always review and confirm every critical operation (file deletion, shell commands, email sending, etc.).
Use dry_run=True whenever possible, and treat the LLM as an assistant, not an autonomous executor.

🤝 We need your help – across programs and operating systems!
This project currently runs on Windows, but it is written in cross‑platform Python.
I need your help to:

🐧 Test on Linux and macOS – report bugs, fix path issues, adapt shell commands.

🔌 Integrate with other MCP clients – Claude Desktop, Continue, Zed, etc.

🛡️ Improve security – suggest better sandboxing, privilege separation, or audit the existing protections.

📖 Write user guides for different environments.

Every contribution – even a single bug report – is valuable.
You do not need to send money. Just your time and expertise.
